# Supercycl 사용자 가이드 페이지 — 설계 문서

**날짜**: 2026-06-12
**상태**: 사용자 승인 완료
**산출물 위치**: `Supercycl-Guide/` (이 저장소)

## 목적

Supercycl-Mobile 앱(거래소 애그리게이터 선물 거래 PWA)의 주요 사용 흐름을 안내하는 HTML 기반 사용자 가이드 페이지를 만든다. 연령대가 높은 사용자도 쉽게 이해할 수 있도록 직관적이고 친절하게 구성하며, **온보딩(로그인 → 거래소 연동 → 첫 거래 화면 진입)** 을 가장 상세히 다룬다.

## 확정된 요구사항

| 항목 | 결정 |
|---|---|
| 콘텐츠 범위 | 온보딩(상세) + Markets/Trade/Portfolio/Profile 4탭 핵심 기능(간결) |
| 언어 | 한국어(기본) / English — JS 토글, localStorage에 선택 유지 |
| 산출물 형태 | `index.html` + `images/` 폴더 (정적, 빌드 도구 없음) |
| 가이드 테마 | 앱과 동일한 Dark Pro + Glass-forward + Mono Green, 시니어 가독성 보정 |
| 탐색 구조 | 단일 스크롤 + 상단 목차 카드 + 고정 헤더(현재 섹션 표시) |
| 화면 이미지 | Supercycl-Mobile 로컬 서버를 띄워 디자인 모드 실제 화면을 Playwright로 캡처 |

## 파일 구조

```
Supercycl-Guide/
├── index.html          # 가이드 본문 (한/영 텍스트 모두 포함)
├── assets/
│   ├── guide.css       # 스타일 (Supercycl 디자인 토큰 차용)
│   └── guide.js        # 언어 토글 + 목차 스크롤 + 현재 위치 표시
├── images/             # 캡처된 화면 (scr-XXX.png)
└── tools/
    └── capture.mjs     # Playwright 캡처 스크립트 (재실행 가능)
```

## 페이지 구성 (단일 스크롤, 위→아래)

1. **고정 헤더** — Supercycl 로고 + 언어 토글(한국어 | English, 현재 언어 Mono Green 하이라이트). 스크롤 시 현재 섹션 이름 표시.
2. **인트로** — "Supercycl이 처음이신가요?" 한 문단. 여러 거래소를 한 곳에서 거래하는 서비스라는 점을 쉬운 말로 소개.
3. **목차 카드** — 큰 글씨 번호 카드 5개, 탭하면 해당 섹션으로 부드럽게 스크롤: ① 시작하기 ② Markets ③ Trade ④ Portfolio ⑤ Profile.
4. **섹션 1 — 시작하기 (온보딩, 가장 상세)** — STEP 카드 5개. 각 카드는 [캡처 이미지(폰 프레임)] + [큰 제목] + [설명] + [필요 시 주의/안심 박스] 구조로 통일:
   - **STEP 1. 로그인** — SCR-001 캡처. 이메일 / Google / QR 세 가지 방법 설명.
   - **STEP 2. 거래소 연결 안내** — SCR-807 캡처. "왜 거래소 연결이 필요한가요?" 설명 + ⚠️ "건너뛰면 거래를 할 수 없어요" 주의 박스.
   - **STEP 3. 거래소 선택** — SCR-812 캡처. 현재 OKX만 연결 가능(나머지는 Coming Soon) 안내.
   - **STEP 4. 연결 승인** — SCR-801 캡처. 요청 권한 설명 + 🔒 안전한 이유(출금 권한 없음 등) 안심 박스.
   - **STEP 5. 연결 완료 & 첫 화면** — SCR-802 + SCR-102 캡처. 홈 화면 추가(설치) 프롬프트 SCR-720 안내.
5. **섹션 2~5 — 4탭 핵심 기능 (각 1~3개 화면, 간결)**:
   - **Markets** (SCR-301) — 시세 보기, 종목 검색.
   - **Trade** (SCR-102) — 주문 화면 읽는 법, 매수/매도 기본.
   - **Portfolio** (SCR-401/402) — 내 자산과 포지션 확인.
   - **Profile** (SCR-403) — 거래소 관리, 알림 설정, 앱 설치.
6. **푸터** — 자주 묻는 질문 2~3개(예: "거래소 연결을 건너뛰었어요, 어떻게 다시 하나요?" → Profile > Connect Exchange 재유도) + 문의 안내.

## 기술 설계

### 언어 토글 (i18n)

- 번역 대상 요소에 `data-i18n="키"` 속성, `guide.js` 내 번역 객체(`ko` / `en`)에서 텍스트 주입.
- 기본 언어 한국어. 토글 시 `<html lang>` 갱신, 선택은 `localStorage`에 저장.
- 이미지 `alt` 텍스트도 한/영 모두 제공하고 토글 시 함께 전환.

### 디자인

- Supercycl-Mobile 디자인 토큰 차용 (`assets/design-spec/styles/tokens-design.css` 기준):
  - 배경: `linear-gradient(160deg, #060610 0%, #0A1510 50%, #050508 100%)`
  - 액센트: `#00E676` (Mono Green) + 그라디언트 `linear-gradient(135deg, #7EF0A8, #00E676)`
  - 폰트: IBM Plex Sans + 한글 폴백(Pretendard / Noto Sans KR)
  - 글래스 카드: 반투명 배경 + backdrop blur + 얇은 테두리
- **시니어 가독성 보정**: 본문 기본 18px 이상, 줄간격 1.7, STEP 번호 56px 원형 배지, 본문 순백(#FFF) 고대비, 터치 타깃 48px 이상.
- 캡처 이미지는 폰 프레임(둥근 모서리 + 얇은 테두리 + 은은한 그린 글로우) 안에 배치. 탭 위치 안내는 이미지 편집 없이 CSS 오버레이 라벨("여기를 누르세요" + 화살표)로 처리.
- 주의사항: ⚠️ + 노란 톤 박스 / 안심 정보: 🔒 + 그린 톤 박스로 일관 구분.

### 동작 (guide.js — 외부 의존성 없음)

- 언어 토글, 목차 클릭 시 부드러운 스크롤, 스크롤 위치 기반 고정 헤더 현재 섹션 표시. 외부 라이브러리 사용 안 함.

### 캡처 스크립트 (tools/capture.mjs)

- 전제: Supercycl-Mobile에서 `npm run dev` 실행 중 (`http://localhost:8080`), E2E 인증 세션 존재 (`Supercycl-Mobile/tests/e2e/.auth/default.json`).
- 동작: `design-spec.html` 접속 → `switchViewMode('design')`으로 디자인 모드 전환 → 대상 화면 ID 목록을 순회하며 각 `#scr-XXX` 요소를 `deviceScaleFactor: 2`로 캡처 → `images/scr-XXX.png` 저장.
- 대상 화면 (11장, 전부 design-spec.html 존재 확인 완료): scr-001, scr-807, scr-812, scr-801, scr-802, scr-102, scr-720, scr-301, scr-401, scr-402, scr-403 (+ 필요 시 추가).
- 재실행 가능하게 작성 — 목업 변경 시 `node tools/capture.mjs`로 이미지 갱신.
- 에러 처리: 서버 미실행·인증 세션 만료 시 명확한 안내 메시지를 출력하고 중단.

## 검증 기준

- 브라우저에서 한/영 전환이 모든 텍스트(alt 포함)에 적용된다.
- 목차 클릭 시 해당 섹션으로 스크롤되고, 고정 헤더에 현재 섹션이 표시된다.
- 캡처 이미지 11장이 디자인 모드(Dark Pro + Mono Green) 기준으로 선명하게(2x) 들어가 있다.
- 데스크톱과 모바일 폭 모두에서 레이아웃이 깨지지 않는다.
- 기본 언어가 한국어이고, 새로고침 후에도 선택 언어가 유지된다.

## 범위 제외 (YAGNI)

- 빌드 도구, 프레임워크, 외부 JS 라이브러리.
- 다크/라이트 테마 토글 (다크 고정).
- 검색 기능, 동영상 가이드.
- 한/영 외 추가 언어.
